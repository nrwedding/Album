NIZAR & RINSHA FEBIN — WEDDING WEBSITE

Open index.html in a web browser to preview.
To deploy to Vercel: upload this folder to a GitHub repository, then import the repository in Vercel as an Other/static project. No build command is required. The output directory is the repository root.

All 12 original uploaded photos are in images/. The download button serves the included original file.

Future Google Drive integration: replace the static image array with a generated gallery manifest and serve optimized thumbnails and downloadable originals. Review guest consent before publishing.
